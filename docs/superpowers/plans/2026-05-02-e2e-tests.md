# E2E Tests Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add Playwright E2E tests covering the three critical happy paths (app loads, HvAI game completes, AIvAI game completes), wired into GitHub Actions CI.

**Architecture:** Playwright is installed as a devDependency in `web/`. A `playwright.config.js` serves the app via `python3 -m http.server 8080` from the repo root (so `web/batalha_naval/` is reachable). Tests live in `web/e2e/game.spec.js`. A `make test-e2e` target runs them. A new `e2e` CI job runs `make build-web` then `make test-e2e`.

**Tech Stack:** Playwright (`@playwright/test`), Python HTTP server, GitHub Actions

### Task 3: Write E2E tests

**Files:**
- Create: `web/e2e/game.spec.js`

- [ ] **Step 1: Create the test file**

Create `web/e2e/game.spec.js` with this exact content:

```js
import { test, expect } from "@playwright/test"

async function waitForPyodide(page) {
  await expect(page.locator("#loading-indicator")).toHaveClass(/hidden/, {
    timeout: 60_000,
  })
}

test("app loads and Pyodide initialises", async ({ page }) => {
  await page.goto("/")
  await waitForPyodide(page)

  await expect(page.locator("#btn-start")).toBeEnabled()
  await expect(page.locator("#board-player")).toBeVisible()
  await expect(page.locator("#board-enemy")).toBeVisible()
})

test("HvAI game plays to completion", async ({ page }) => {
  await page.goto("/")
  await waitForPyodide(page)

  // Select random strategy so the game is fast
  await page.locator("#select-strategy-hvai").selectOption({ label: "Aleatória" })

  // Shuffle ship placement
  await page.locator("#btn-shuffle").click()

  // Wait for all ships placed (btn-start becomes enabled)
  await expect(page.locator("#btn-start")).toBeEnabled()
  await page.locator("#btn-start").click()

  // Play: click available cells on enemy board until end-banner appears
  for (let i = 0; i < 120; i++) {
    const ended = await page.locator("#end-banner").isVisible()
    if (ended) break

    const clickable = page.locator("#board-enemy .cell.clickable").first()
    const hasClickable = await clickable.count() > 0
    if (!hasClickable) {
      // AI is taking its turn — wait briefly and retry
      await page.waitForTimeout(500)
      continue
    }

    await clickable.click()
    // Wait for this cell to lose the clickable class (attack registered)
    await expect(clickable).not.toHaveClass(/clickable/, { timeout: 15_000 })
  }

  await expect(page.locator("#end-banner")).toBeVisible()
  await expect(page.locator("#end-message")).not.toBeEmpty()
})

test("AIvAI game plays to completion", async ({ page }) => {
  await page.goto("/")
  await waitForPyodide(page)

  // Switch to AIvAI mode
  await page.locator("#btn-aivai").click()

  // Select random strategy for both AIs
  await page.locator("#select-strategy-p1").selectOption({ label: "Aleatória" })
  await page.locator("#select-strategy-p2").selectOption({ label: "Aleatória" })

  // Shuffle placements for both sides
  for (const btn of await page.locator(".btn-shuffle-side").all()) {
    await btn.click()
  }

  // Wait for start button to be enabled (all ships placed)
  await expect(page.locator("#btn-start")).toBeEnabled()
  await page.locator("#btn-start").click()

  // AIs drive the game automatically — just wait for end-banner
  await expect(page.locator("#end-banner")).toBeVisible({ timeout: 120_000 })
  await expect(page.locator("#end-message")).not.toBeEmpty()
})
```

### Task 5: CI job

**Files:**
- Modify: `.github/workflows/test.yml`

- [ ] **Step 1: Add the e2e job**

Append the following job to `.github/workflows/test.yml` (after the `js:` job):

```yaml
  e2e:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - uses: actions/setup-node@v4
        with:
          node-version-file: web/.nvmrc

      - name: Install JS dependencies
        run: npm ci
        working-directory: web

      - name: Install Playwright browsers
        run: npx playwright install --with-deps chromium
        working-directory: web

      - uses: actions/setup-python@v5
        with:
          python-version: "3.x"

      - name: Build web (copy Python files)
        run: make build-web

      - name: Run E2E tests
        run: make test-e2e
```
